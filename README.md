# RunsArt: ศูนย์รวมเครื่องมือวิเคราะห์การวิ่ง (Vercel + Supabase + Strava)

## โครงสร้างโฟลเดอร์ (อัปโหลดทั้งโฟลเดอร์ขึ้น Vercel)

    index.html                 หน้าแรก (ศูนย์รวมเครื่องมือ)
    tools/slope/index.html     เครื่องมือ: ความชันและความยากเส้นทาง
    tools/training analysis/   เครื่องมือ: วิเคราะห์การซ้อม
    tools/race planner/        เครื่องมือ: วางแผนแข่ง
    config.js                  ค่า Supabase (ใส่ครั้งเดียว ใช้ทุกหน้า)
    supabase.sql               สร้างตารางฐานข้อมูล
    api/                       ฟังก์ชันฝั่งเซิร์ฟเวอร์สำหรับ Strava
    package.json

เปิดเว็บที่ `/` จะเป็นหน้าแรก ลาก/เลือกไฟล์ก่อน แล้วเลือกเครื่องมือจากหน้าต่างที่แสดงขึ้น หรือเข้าเครื่องมือจากแถบเครื่องมือด้านบน
ทุกหน้าใช้แถบเดียวกันเพื่อสลับระหว่างหน้าแรก แผนที่/แบ่งช่วง วิเคราะห์การซ้อม และวางแผนแข่งได้ โดยไฟล์ล่าสุดจะอยู่ให้ใช้ต่อเมื่อสลับหน้า
หน้าวิเคราะห์การซ้อมแสดงกราฟเพซ/หัวใจใต้แผนที่ GPS ในกรอบเดียวกัน ทั้งสองมุมมองใช้ระยะทางเดียวกันและเลื่อนตำแหน่งพร้อมกันได้ สำหรับ Interval/Tempo ให้เปิด “ปรับรอบบนกราฟ” แล้วลากขอบซ้าย/ขวาของแถบรอบเพื่อแก้จุดเริ่ม/จบ หรือแก้เวลาเป็นวินาทีในตาราง; หากระบบพลาดรอบ ให้เลือก “เพิ่มรอบโดยลาก” แล้วลากครอบช่วงเร็วบนกราฟ ปุ่ม “เลิกทำ” และ “ทำซ้ำ” ใช้ย้อนการแก้ไขได้
การล็อกอินใช้ร่วมกัน ล็อกอินที่หน้าไหนก็ได้ ทุกหน้าจะรู้จัก

## ตั้งค่า (ทำครั้งเดียว)

### Supabase
1. สร้างโปรเจกต์ แล้วรัน `supabase.sql` ใน SQL Editor
2. Project Settings > API คัดลอก Project URL กับ anon public key ใส่ใน `config.js`
3. Authentication > URL Configuration
   - Site URL: `https://runsart.vercel.app`
   - Redirect URLs เพิ่ม `https://runsart.vercel.app/**` (ต้องมี `/**` เพราะตอนนี้มีหลายหน้า)
4. Authentication > Sign In / Providers > Email ปิด Confirm email ถ้าอยากให้สมัครแล้วเข้าได้ทันที

### Strava
1. strava.com/settings/api สร้างแอป ช่อง Authorization Callback Domain ใส่ `runsart.vercel.app`
2. คัดลอก Client ID และ Client Secret

### Vercel > Settings > Environment Variables
`SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `STRAVA_CLIENT_ID`, `STRAVA_CLIENT_SECRET`, `STATE_SECRET`
(`SUPABASE_SERVICE_ROLE_KEY` เป็นความลับ ห้ามใส่ใน config.js) แล้ว Redeploy

ถ้า Strava อนุญาตแล้วแต่บันทึก token ไม่สำเร็จ ให้ตรวจว่า Vercel มี `SUPABASE_URL` และ `SUPABASE_SERVICE_ROLE_KEY` (service role key ไม่ใช่ anon key) และรัน `supabase.sql` ในโปรเจกต์เดียวกันเพื่อสร้างตาราง `public.strava_tokens` แล้ว Redeploy หลังแก้ Environment Variables

ถ้าโหลดกิจกรรมจาก Strava ไม่ได้และ API ตอบ 409 หลัง Strava ปฏิเสธคำขอ ให้กดเชื่อมต่อ Strava ใหม่และกดอนุญาตสิทธิ์อ่านกิจกรรม

ถ้า Vercel log แสดง `resource: "Application"`, `field: "Status"`, `code: "Inactive"` แสดงว่าแอป Strava ถูกปิดใช้งาน ต้องให้เจ้าของแอปตรวจสอบ/แก้สถานะใน Strava API Settings ก่อน การเชื่อมบัญชีผู้ใช้อีกครั้งไม่สามารถแก้สถานะแอปได้

## วิธีเพิ่มเครื่องมือใหม่ (ทีละตัว)
1. สร้างโฟลเดอร์ `tools/ชื่อเครื่องมือ/` ใส่ `index.html` ของเครื่องมือนั้น
   - ใส่ `<script src="/config.js"></script>` ถ้าต้องใช้บัญชี
   - ใส่ลิงก์ `<a href="/">← หน้าแรก</a>` ไว้กลับหน้าแรก
2. ที่ `index.html` หน้าแรก คัดลอกการ์ด `<a class="card" ...>` อันเดิมไปวางต่อในกลุ่มเดียวกัน แล้วแก้ชื่อ คำอธิบาย ลิงก์ และคำค้น (`data-kw`) การ์ด "เครื่องมือถัดไปกำลังมา" เก็บไว้ท้ายสุดหรือลบออกเมื่อครบก็ได้
3. ถ้าเครื่องมือนั้นต้องใช้ Strava แล้วให้เด้งกลับหน้าตัวเอง เพิ่มพาธ เช่น `/tools/pace/` ในรายการ `BACK` ที่ไฟล์ `api/_lib.js`

## ส่งของจากหน้าแรกไปเครื่องมือ
- ไฟล์ .gpx/.tcx ที่ลากมาวางหรือเลือกจากหน้าแรก: เลือกเครื่องมือหลังเลือกไฟล์ เก็บชั่วคราวใน sessionStorage และเปิดอ่านให้เอง
- เครื่องมือแผนที่มีกราฟความสูง แผนที่เส้นทาง และเครื่องมือแบ่ง/ตัดช่วงด้วยตนเอง
- เครื่องมือวิเคราะห์การซ้อมรับไฟล์หลายไฟล์พร้อมกันและบันทึกผลอัตโนมัติในบัญชี (หากตั้งค่า Supabase) หรือเบราว์เซอร์นี้
- หน้าวิเคราะห์การซ้อมวางแผนที่สี่เหลี่ยมจัตุรัสและกราฟเพซ/หัวใจในกรอบเดียวที่ใช้ความกว้างเนื้อหาเท่าหน้าความชัน; toolbar ไอคอนอยู่ขวากราฟบนจอกว้างและเรียงเหนือกราฟบนมือถือ
- เครื่องหมาย ⓘ หลังหัวข้อและค่าต่าง ๆ ใช้ชี้เพื่ออ่านคำอธิบายเฉพาะรายการ แทนกล่องอภิธานศัพท์รวม
- เครื่องมือวางแผนแข่งคำนวณเพซตามความชัน แบ่งโปรไฟล์ด้วย RDP แบบเดียวกับหน้าแผนที่/แบ่งช่วง โดยใช้ค่าคลาดเคลื่อนของระดับความสูงที่เริ่มจาก 3% ของช่วงสูงต่ำสุดและปรับให้อัตโนมัติเมื่อเกิน 30 ช่วง; ปรับความละเอียดเองได้ด้วยแถบเลื่อน และลงสีตามความชันเฉลี่ย เลือกโหมดสนามอัตโนมัติจากความสูงสะสมและช่วงชัน (หรือเลือกเอง) กราฟและแผนที่ซูม/เลื่อนระยะทางร่วมกันได้; หลังนำเข้าไฟล์จะยังไม่วางจุดเตือนจนกดสร้างเอง; โหมดถนนซ่อนเครื่องมือเทรล การเตือนโพลอิงช่วงแบ่งภูมิประเทศและดูการขึ้นต่อเนื่องจนถึงยอด โดยแนะนำเฉพาะเนินยาวและมีช่วงชันพอ ตั้งช่วงเจลและเกลือแร่เป็นนาที และแสดง UTMB Index โดยประมาณเฉพาะโหมดเทรล (ไม่ใช่คะแนนทางการ)
- ในเครื่องมือทั้งสองสามารถสลับไปใช้อีกเครื่องมือด้วยไฟล์ล่าสุดที่นำเข้าได้
- หน้า Training Analysis ให้อัปโหลดไฟล์ก่อน ระบบเริ่มด้วยการตรวจจับชนิดการวิ่งอัตโนมัติ แล้วเลือกหรือเปลี่ยนชนิดได้ภายหลัง
- ไฟล์ GPX/TCX และผลวิเคราะห์บันทึกในบัญชี Supabase เพื่อเปิด/แก้ไขเซสชันข้ามอุปกรณ์ได้; กด “เปิด / แก้ไข” จากประวัติ แล้วกด “อัปเดตเซสชันนี้” เพื่อแทนที่ผลเดิม
- หากใช้ประวัติบน Supabase ให้รัน `supabase.sql` เพื่อสร้างตาราง `public.workouts` และ `public.workout_files`; หากบันทึกไฟล์ต้นฉบับออนไลน์ไม่ได้ ระบบแจ้งข้อผิดพลาด
- เซสชันที่บันทึกก่อนเพิ่มการเก็บไฟล์ต้นฉบับมีเฉพาะผลสรุป ต้องนำเข้า GPX/TCX อีกครั้งจึงจะเปิดแก้ไขได้
- ประวัติ Strava แบบสรุปโหลดได้ทุกหน้าในช่วงวันที่ที่เลือก หลังเชื่อมบัญชี; ข้อมูลนี้เป็นระยะ/เวลา/HR เฉลี่ย ไม่ใช่สตรีมรายละเอียดสำหรับกราฟหรืออินเทอร์วัล
- กิจกรรม Strava: `/tools/slope/?activity=ID`
- เส้นทางที่บันทึก: `/tools/slope/?route=ID`

## หมายเหตุ
- รองรับไฟล์ .gpx และ .tcx (.fit ยังไม่รองรับ; ส่งออกเป็น GPX/TCX ก่อน)
- การตรวจเทรลอัตโนมัติอาศัยชนิดกิจกรรม Trail Run จาก Strava, คำว่า Trail/เทรลในชื่อไฟล์ หรือความสูงสะสมโดยประมาณ; เส้นทาง GPX ที่ไม่มีข้อมูลเหล่านี้ควรเลือกชนิดคอร์สเทรลเอง
- Garmin, Coros, Suunto, Apple Watch ซิงก์เข้า Strava แล้วดึงต่อได้ ไม่มี API ตรงสำหรับผู้ใช้ทั่วไป
- แอป Strava ใหม่เชื่อมได้คนเดียวก่อน ปลดล็อกได้ถึง 10 คนที่หน้า API Settings เกินนั้นต้องส่งตรวจกับ Strava
